## 3. git 入库策略

### 3.1 入库

- `RL/` 下除 `experiments/`、`__pycache__/`、大数组/大 CSV 外的源码、测试、配置、文档；
- `RL/data/` 的小 JSON/manifest/评估报告；
- `RL/BC_checkpoint/bladed_pid_b4_state20_residual_v3.pt`；
- `RL/diagnostics/physical_load_margin_dynamic_v2/frozen_*.json` 与小型 summary；
- `bladed_env/` 的工程文件、DLL 源码、vcxproj、BladedAPI 头/库；
- `doc/` 全部文档与小型图片/CSV；
- `.vscode/settings.json`、`.gitignore`、根 `README.md`（后续新增）。

### 3.2 不入库

- `RL/experiments/`、`bladed-data/`、`bladed-data-new/`、`bladed_result/`；
- 81 MB / 25 MB paired reference、BC 源 CSV、`.rl_cache/`、预测器 `.npz`；
- `RL/BC_checkpoint/inference/`、`RL/diagnostics/` 的大 CSV/JSONL/演示输出；
- Windows 构建产物（`.vs/`、`Release/`、`x64/`、`*.pdb`、`*.obj`、`*.dll`、`*.lib` 构建件）；
- 日志、缓存、编辑器临时文件。

### 3.3 备注

- 当前 `git-lfs` 未安装；不建议把 84 MB JSON 直接提交到普通 git 对象库。
- 大工件以现有 SHA/manifest 管理；迁移到新机器时按清单从外部存储恢复。
- 若后续确需版本化大工件，先安装 LFS 或改用外部制品库，再更新本节。
