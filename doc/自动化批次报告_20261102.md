## 2. M3：可观测性

### 2.1 影子健康

`RL/utils/physical_load_shadow.py` 新增 `shadow_health()`，并写入 `summary()['health']`：

- `status`: `OK` / `DEGRADED` / `FAULTED` / `NOT_FINAL`
- `reasons`: 具体原因（invalid submissions、queue drop、worker fault、未 finalize）
- 计数：submitted / invalid / dropped / worker_faults / records / finished / strict_complete
- `submission_success_rate`

这样影子故障不再只体现在零散 counter 里，运行结束可直接判断“载荷诊断是否可用”。

### 2.2 Q-gate 生效类型

`RL/utils/critic_q_health.py` 新增 `resolve_actor_gate_mode()`；`train_rl.py` 用它决定实际实例化哪个 gate，并打印：

```text
[Queue] actor_gate=optimizer trend_configured=True optimizer_configured=True note=optimizer gate takes precedence; trend gate configured but not instantiated
```

可选配置 `train.actor_gate_mode`：`auto`（默认）/ `trend` / `optimizer` / `none`。显式指定与 enabled 不一致时直接报错。

## 3. M6A：`run_meta` 与时间戳目录（兼容模式）

### 3.1 新增模块

`RL/run_meta.py`：

- `git_info()`：commit、dirty、changed files、diff stat；
- `make_run_label()`：`YYYYMMDDTHHMMSSZ_<shortsha>`；
- `make_run_dir()`：创建 `runs/<label>/`，拒绝覆盖；
- `write_run_meta()`：写 `run_meta.json`（幂等），含 git、配置快照/SHA、设备、工件哈希、主机/Python；
- CLI：`python -m RL.run_meta --config ... --base-dir runs`。

### 3.2 接入训练

`train_rl.py` 在 `_run_initialized_training` 创建 logger 后写入 `run_meta.json`（legacy 模式，仍使用现有 `RL/experiments/<experiment_name>/`）。写失败只告警，不阻断训练。

**M6A 没有删除 RUN_ID、receipt、release manifest 或 DLL 环境变量**；这些属于 M6B。
