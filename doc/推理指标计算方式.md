# 推理指标计算方式

## 1. 文档目的

本文规定 frozen inference 与 PID 对比结果的统一计算方式，主要解释：

- RL/PID 数据如何匹配；
- 累计发电量如何计算；
- 平均功率和累计能量的关系；
- 三片叶根 My 极限载荷如何计算；
- 发电量与载荷的最终验收规则；
- 边缘服务器推理时延和输出频率如何计算。

当前绘图入口：

```bash
python RL/infer/plot_inference_vs_pid.py \
  --inference-dir <inference_directory> \
  --pid-csv bladed-data-new/raw/data_windspeed<ID>.csv
```

主要实现文件：

```text
RL/infer/plot_inference_vs_pid.py
RL/infer/analyze_edge_performance.py
```

## 2. 输入数据

### 2.1 RL inference 数据

每个风况的 inference 目录中需要包含：

```text
bladed_inference_steps.csv
```

绘图脚本只读取：

```text
record_type = control_step
```

需要的主要字段包括：

```text
Time
I_AverageWindSpeed
Electrical power
Blade root 1 My (Nm)
Blade root 2 My (Nm)
Blade root 3 My (Nm)
sent_action_torque
sent_action_pitch
info_control_fallback_active
info_control_ood_score
```

其中：

- `Time`：Bladed 仿真时间，单位 s；
- `Electrical power`：电功率，单位 W；
- 三个 `Blade root * My (Nm)`：三个叶根 My，单位 Nm；
- `sent_action_torque`：RL 实际发送的扭矩，单位 Nm；
- `sent_action_pitch`：RL 实际发送的桨距，单位 rad。

### 2.2 PID 数据

PID 对比文件为：

```text
bladed-data-new/raw/data_windspeed<ID>.csv
```

例如：

```text
3 m/s  -> bladed-data-new/raw/data_windspeed3.csv
10 m/s -> bladed-data-new/raw/data_windspeed10.csv
25 m/s -> bladed-data-new/raw/data_windspeed25.csv
```

PID CSV 需要包含：

```text
Time
I_AverageWindSpeed
Electrical power
O_PcsTorqueDemand
O_PitchPositionDemand1
Blade root 1 My (Nm)
Blade root 2 My (Nm)
Blade root 3 My (Nm)
```

## 3. RL/PID 时间和样本对齐

### 3.1 样本数量

设 RL inference 中有效的 `control_step` 数量为 $N$。

绘图脚本从 PID CSV 的 `pid_start_row` 开始读取 $N$ 行：

```text
默认 pid_start_row = 0
```

默认匹配关系为：

$$
\mathrm{RL}[i]\leftrightarrow\mathrm{PID}[i],
\quad i=0,1,\ldots,N-1
$$

如果 PID 文件前面有 settling 行或其他无效窗口，可以使用：

```bash
--pid-start-row <offset>
```

### 3.2 elapsed time

RL 和 PID 分别读取自己的 `Time` 列：

$$
 t^{RL}_i,
\qquad
 t^{PID}_i
$$

每条轨迹的 elapsed time 都从自身首帧归零：

$$
 \tau^{RL}_i=t^{RL}_i-t^{RL}_0
$$

$$
 \tau^{PID}_i=t^{PID}_i-t^{PID}_0
$$

普通图的横轴使用：

```text
Elapsed simulation time (s)
```

当前典型 600 s 数据为：

```text
0.00, 0.02, 0.04, ..., 600.00 s
```

### 3.3 Formal acceptance 的严格要求

启用：

```bash
--formal-acceptance
```

时，必须满足：

1. RL 和 PID 样本数相同；
2. RL 只有一个连续 episode；
3. RL 时间戳严格递增；
4. PID 时间戳严格递增；
5. 两条轨迹的相对时间网格一致；
6. 时间对齐误差不超过 $1\times10^{-9}\ \mathrm{s}$。

不满足时，formal report 会标记：

```text
valid = false
```

## 4. 累计发电量计算

### 4.1 单区间梯形积分

设相邻两个采样点为：

- 当前时间：$t_i$；
- 下一时间：$t_{i+1}$；
- 当前功率：$P_i$；
- 下一功率：$P_{i+1}$。

单个时间区间的能量使用梯形积分：

$$
\Delta E_i
=
\frac{P_i+P_{i+1}}{2}
\left(t_{i+1}-t_i\right)
$$

其中：

```text
P 单位：W
t 单位：s
Delta E 单位：J
```

### 4.2 J 转换为 MWh

因为：

$$
1\ \mathrm{MWh}
=
10^6\ \mathrm{W}\times3600\ \mathrm{s}
=
3.6\times10^9\ \mathrm{J}
$$

所以：

$$
\Delta E_{i,\mathrm{MWh}}
=
\frac{
\frac{P_i+P_{i+1}}{2}
\left(t_{i+1}-t_i\right)
}{3.6\times10^9}
$$

### 4.3 累计能量

起点定义为：

$$
E_0=0
$$

之后逐段累加：

$$
E_k
=
E_{k-1}
+
\frac{
\frac{P_{k-1}+P_k}{2}
\left(t_k-t_{k-1}\right)
}{3.6\times10^9}
$$

代码对应：

```python
cumulative = np.zeros(len(power_w), dtype=np.float64)

for index in range(1, len(power_w)):
    delta_s = max(
        0.0,
        float(elapsed_time_s[index] - elapsed_time_s[index - 1]),
    )
    cumulative[index] = (
        cumulative[index - 1]
        + 0.5
        * (power_w[index - 1] + power_w[index])
        * delta_s
        / 3.6e9
    )
```

RL 和 PID 分别计算：

$$
E_{RL}(t)
\qquad\text{和}\qquad
E_{PID}(t)
$$

累计能量图中：

- 蓝线：$E_{RL}(t)$；
- 红线：$E_{PID}(t)$；
- 绿色差值线：

$$
\Delta E(t)=E_{RL}(t)-E_{PID}(t)
$$

### 4.4 累计能量差值和相对变化率

绝对差值：

$$
\Delta E_{abs}=E_{RL}-E_{PID}
$$

相对 PID 的变化率：

$$
\Delta E_{percent}
=
\left(\frac{E_{RL}}{E_{PID}}-1\right)\times100\%
$$

当 $E_{PID}>0$ 时该比率有效。

解释：

```text
Delta E_percent > 0: RL 比 PID 多发电
Delta E_percent = 0: RL 与 PID 相同
Delta E_percent < 0: RL 比 PID 少发电
```

### 4.5 为什么不是平均功率乘时间

平均功率乘总时间只能作为近似：

$$
E_{approx}
=
\frac{\bar P\times T}{3.6\times10^9}
$$

正式绘图使用逐区间梯形积分，因为：

- 功率会随时间变化；
- 每个时间间隔使用实际时间戳；
- 仿真可能存在暂停或非均匀采样；
- 梯形积分更接近真实功率曲线的面积。

## 5. Wind10 计算示例

对应输入：

```text
RL inference:
<inference_directory>

PID:
bladed-data-new/raw/data_windspeed10.csv
```

前两个 RL 采样点：

```text
t0 = 0.00 s
P0 = 10,486,924 W

t1 = 0.02 s
P1 = 10,479,265 W
```

第一段 RL 能量：

$$
\begin{aligned}
\Delta E_{RL,1}
&=
\frac{10{,}486{,}924+10{,}479{,}265}{2}
\times0.02\\
&=209{,}661.89\ \mathrm{J}\\
&=5.82394\times10^{-5}\ \mathrm{MWh}
\end{aligned}
$$

同一时间区间的 PID 数据为：

```text
P0 = 10,486,924 W
P1 = 10,608,203 W
```

得到：

$$
\Delta E_{PID,1}=5.85976\times10^{-5}\ \mathrm{MWh}
$$

600 s 结束时：

```text
RL  = 1.8519305068 MWh
PID = 1.9318594724 MWh
```

累计差值：

$$
E_{RL}-E_{PID}
=
-0.0799289657\ \mathrm{MWh}
$$

相对变化率：

$$
\Delta E_{percent}
=
\left(
\frac{1.8519305068}{1.9318594724}-1
\right)\times100\%
=-4.1374\%
$$

## 6. 平均功率指标

平均功率是采样点功率的算术平均：

$$
\bar P
=
\frac{1}{N}\sum_{i=0}^{N-1}P_i
$$

平均功率用于图中注释和 summary 统计，但累计能量使用梯形积分。

Wind10：

```text
RL 平均功率  = 11.111514 MW
PID 平均功率 = 11.591097 MW
Delta P       = -4.14%
```

## 7. 三片叶根 My 极限载荷

只使用：

```text
Blade root 1 My (Nm)
Blade root 2 My (Nm)
Blade root 3 My (Nm)
```

每个通道的极限载荷为有效时间窗内绝对值最大值：

$$
L_{j,RL}=\max_i\left|M^{My}_{j,RL,i}\right|
$$

$$
L_{j,PID}=\max_i\left|M^{My}_{j,PID,i}\right|
$$

第 $j$ 个叶片相对 PID 的载荷降低率：

$$
\Delta L_j
=\left(1-\frac{L_{j,RL}}{L_{j,PID}}\right)\times100\%
$$

解释：

```text
Delta L_j > 0: RL 载荷低于 PID
Delta L_j = 0: RL 与 PID 相同
Delta L_j < 0: RL 载荷高于 PID
```

整体载荷指标取最差叶片：

$$
\Delta L=\min(\Delta L_1,\Delta L_2,\Delta L_3)
$$

`inference_vs_pid_blade_root_my.png` 的每个叶片子图标题显示：

```text
RL peak
PID peak
RL - PID absolute difference
RL - PID relative percentage
```

## 8. 发电量与载荷最终验收

定义：

```text
P0: Delta E >= 0%
P1: Delta E >= 1%
L0: Delta L >= 0%
L1: Delta L >= 1%
```

最终规则：

$$
(P_1\land L_0)\lor(L_1\land P_0)
$$

### 路径 1：发电优先

$$
\Delta E\geq1\%
\quad\land\quad
\Delta L\geq0\%
$$

### 路径 2：降载优先

$$
\Delta L\geq1\%
\quad\land\quad
\Delta E\geq0\%
$$

## 9. 边缘服务器推理性能

### 9.1 端到端时延

每个控制周期记录：

- $t_{rx,i}$：边缘服务器接收完整观测包的时间；
- $t_{tx,i}$：动作包完成发送调用的时间。

$$
T_{e2e,i}
=(t_{tx,i}-t_{rx,i})\times1000\ \mathrm{ms}
$$

$$
P99(T_{e2e})=Q_{0.99}\left(\{T_{e2e,i}\}\right)
$$

### 9.2 实际输出频率

$$
 f_{out}
=\frac{N-1}{t_{tx,N}-t_{tx,1}}
$$

目标：

$$
P99(T_{e2e})\leq20\ \mathrm{ms}
\quad\land\quad
f_{out}\geq50\ \mathrm{Hz}
$$

## 10. Formal acceptance 与普通绘图

普通绘图用于生成：

- 功率曲线；
- 累计能量曲线；
- 风速曲线；
- 叶根载荷曲线；
- 动作曲线；
- 匹配后的逐步 CSV。

启用 `--formal-acceptance` 后，程序额外生成严格验收报告，并检查：

1. RL/PID control step 数量一致；
2. RL 为单一连续 episode；
3. RL/PID 时间戳严格递增；
4. RL/PID 相对时间网格一致；
5. PID 能量为有限正数；
6. 三个 PID 叶根峰值有限且为正数。

正式能量指标：

$$
E_C
=\frac{1}{3.6\times10^9}
\sum_{i=1}^{N-1}
\frac{P_{C,i-1}+P_{C,i}}{2}
(t_i-t_{i-1})
$$

## 11. 常见误读

### 11.1 平均功率不是累计能量

平均功率单位为 MW，累计能量单位为 MWh。不能直接把平均功率数值当作累计发电量。

### 11.2 绿色曲线不是瞬时功率差

累计能量图下方的绿色曲线是：

$$
E_{RL}(t)-E_{PID}(t)
$$

不是：

$$
P_{RL}(t)-P_{PID}(t)
$$

### 11.3 负的 Delta L 表示载荷增加

$$
\Delta L_j=1-\frac{L_{j,RL}}{L_{j,PID}}
$$

所以：

```text
Delta L_j = -10% 表示 RL 载荷比 PID 高 10%
Delta L_j = +10% 表示 RL 载荷比 PID 低 10%
```

### 11.4 600 s 仿真不等于 600 s wall-clock

指标中的 600 s 是 Bladed 仿真时间，不是 Linux 进程实际运行的墙钟时间。实际 wall-clock 时长会受到 UDP、Windows VM 和 Bladed 求解速度影响。
